# 비밀번호 프로세스 정리 및 고객 혼란 방지

## 1. 구매 단계에서의 비밀번호 검증

- **기존 비밀번호가 있는 고객**: Step 1에서 "기존 비밀번호 입력" 후 **다음 단계로** 버튼을 누르면, 입력한 비밀번호가 실제 비밀번호와 일치하는지 **Supabase signInWithPassword**로 검증합니다.
  - 일치하지 않으면: "비밀번호가 일치하지 않습니다. 다시 입력해 주세요." 알림 후 진행 불가.
  - 일치하면: 다음 단계(약관 동의)로 진행.
- **비밀번호를 처음 설정하는 고객**(매직 링크 로그인 등): 8자 이상 + 비밀번호 확인 일치만 확인하며, 별도 "기존 비밀번호" 검증은 하지 않습니다.

## 2. 고객 혼란 방지를 위한 유도 (적용된 내용)

### 로그인 직후 인지시키기
- **로그인 페이지**: 매직 링크 발송 후 안내 문구에  
  "로그인 후 **비밀번호를 한 번 설정**해 두시면, 다음부터는 이메일+비밀번호만으로 로그인할 수 있고, 구매 시에도 비밀번호 입력이 더 간단해집니다."  
  를 추가해 두었습니다.

### 구매(체크아웃) 단계에서의 유도
- **Step 1 – 비밀번호 설정 시**:  
  - "이미 비밀번호가 있으시면 **기존 비밀번호로 진행**" 링크로, 실수로 설정 모드에 들어온 경우 기존 비밀번호 입력 화면으로 전환할 수 있게 했습니다.  
  - "다음 구매부터는 비밀번호만 입력하면 됩니다. **별도 설정 페이지에서 미리 설정하기**" 링크로 `/set-password?from=/checkout` 이동을 유도해, 원하면 구매 전에 비밀번호를 미리 설정할 수 있게 했습니다.

### 대시보드
- 이미 "비밀번호 설정하기" 배너가 있으므로, 로그인 후 대시보드를 거치는 고객은 그 시점에 비밀번호를 설정할 수 있습니다.

## 3. 정리: 고객이 헷갈리지 않도록

| 상황 | 동작 |
|------|------|
| 매직 링크로 처음 로그인 | 로그인 성공 안내에 "비밀번호 한 번 설정" 혜택 문구 노출. |
| 구매 Step 1에서 비밀번호 없음 | 비밀번호 설정 + "별도 설정 페이지에서 미리 설정하기" 링크로 구매 전 설정 유도. |
| 구매 Step 1에서 비밀번호 있음 | "기존 비밀번호 입력"만 하면 되고, **다음 단계로** 시 서버 검증으로 올바른 비밀번호만 통과. |
| 실수로 "비밀번호 설정" 모드 | "기존 비밀번호로 진행" 클릭 시 기존 비밀번호 입력란으로 전환. |

이 흐름으로 **로그인 직후·구매 전·구매 중** 모두에서 비밀번호를 한 번 설정해 두면 다음 구매가 더 단순해진다는 점이 드러나고, 구매 단계에서는 반드시 **올바른 비밀번호**를 입력해야만 다음 단계로 진행되도록 되어 있습니다.
